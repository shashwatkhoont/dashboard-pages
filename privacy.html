Privacy Policy

Last updated: 18 November 2026

Home Dashboard is a personal, non-commercial application used only by its owner on the owner's own device. This policy explains how it handles Google user data.

Data accessed

  • Google Calendar (read-only): event titles, times and locations for the next few days, to show an agenda.
  • Google Tasks: task titles, due dates and status, to show open tasks, to mark tasks as done or not done when the owner taps them, and to add short notes as tasks.

How data is used and stored

  • Data is used only to display it on the owner's screen and to apply the owner's own changes.
  • A copy is cached in a local database on the owner's device so the screen keeps working offline. The OAuth token is stored only on that device.
  • No data is sent to any server other than Google's own APIs.

Sharing

Google user data is not sold, shared with, or transferred to any third party, and is not used for advertising, analytics or training of any model.

Home Dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the application's data folder on the device removes all cached data.

Contact

Questions: contact the owner through github.com/shashwatkhoont.
